# Security Policy

## Supported versions

Security fixes are provided for the latest release only.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting from the repository's **Security** tab. Include the affected version, reproduction steps, impact, and any suggested remediation. You should receive an initial response within 7 days.

If private reporting is unavailable, open a public issue containing no sensitive details and ask the maintainer for a private contact channel.
